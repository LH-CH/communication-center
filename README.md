# Display v3 — Flat GitHub Build

This build matches a flat GitHub repository. All files belong directly in the repository root.

## Upload these files

- index.html
- admin.html
- styles.css
- admin.css
- display.js
- admin.js
- weather.js
- notices.js
- config.json
- locations.json
- README.md

Do not create `css/` or `js/` folders for this build.

## Fixed refresh schedule

- Config check: 30 minutes
- Full page reload: 30 minutes
- Weather: 10 minutes
- NWS alerts: 5 minutes
- Notice rotation: 10 seconds
