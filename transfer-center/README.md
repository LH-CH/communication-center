# Transfer Center Rollover

**Current version:** 1.3  
**Last updated:** September 21, 2026  
**Owner:** Communication Center

## Purpose

This single-page tool supports Communication Center staff when answering rollover calls for the Transfer Center. It guides the caller intake, displays the appropriate Stroke, Trauma, STEMI, or other-call workflow, and creates a standardized Voalte message.

## How to use

1. Answer with the displayed rollover greeting.
2. Select the call type and complete the required call information.
3. Follow the dynamic workflow shown for the selected call type.
4. Select the appropriate Last Known Normal option for Stroke calls.
5. Use **Copy Message** to place the generated Voalte message on the clipboard, then send it to the required recipient(s).
6. Select **Clear / New Call** before beginning the next call.

## Important behavior

- Required fields must be completed before a Voalte message can be copied.
- The Voalte message text is intentionally not selectable. Use **Copy Message** only.
- Information remains in the browser page only and is not saved by the tool.
