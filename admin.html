One-time GitHub setup

  1. Open GitHub → profile picture → Settings.
  2. Open Developer settings → Personal access tokens → Fine-grained tokens.
  3. Create a token limited to the communication-center repository.
  4. Under repository permissions, set Contents to Read and write.
  5. Choose an expiration date and create the token.
  6. Paste it into the token field on this page, then click Load.

Anyone can open this admin page, but only someone holding a valid repository token can read or save private repository content. For a public repository, reading is public but writing still requires the token.
